# Drag and Drop

A simple drag-and-drop project built with HTML, CSS and JavaScript. This project was created as a hands-on exercise to practise DOM manipulation, event listeners and the browser's Drag and Drop API.

## Features

- Drag cards between lists.
- Highlight a list when a card is dragged over it.
- Move cards into a new list when dropped.
- Use vanilla JavaScript without external libraries.

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.

If you use the VS Code Live Server extension, you can right-click `index.html` and select **Open with Live Server**.

## What I Learned

This project helps practise:

- Selecting elements with `querySelectorAll()` and `getElementById()`.
- Adding event listeners with `addEventListener()`.
- Handling drag-and-drop events such as `dragstart`, `dragover`, `dragenter`, `dragleave` and `drop`.
- Passing data between drag events with `dataTransfer`.
- Updating the page using `appendChild()` and `classList`.
